# Data Model

## Entity: Prompt
- **Description**: Represents the text input provided by the user to the LangChain.js agent.
- **Attributes**:
    - `text`: String (The actual prompt content)

## Entity: Response
- **Description**: Represents the processed text output generated by the LangChain.js agent in response to a prompt.
- **Attributes**:
    - `text`: String (The agent's response content)

## Relationships
- A `Prompt` is sent to the LangChain.js agent, which then generates a `Response`.
